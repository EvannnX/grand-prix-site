## 为什么要两个 prompt

1. **图生 3D 会照搬图里的姿势**:Tripo 把一张图转成一个模型,姿势就固定成图里的样子。同一张图不可能同时给出自然姿势和能绑骨骼的姿势,所以每种姿势都需要单独的源图。
2. **自然姿势没法绑骨骼**:预览图里一只手拿头盔、手臂贴着身体。转成 3D 后,手臂、手和头盔会粘成一整块。自动绑骨骼要求四肢和身体明显分开,T-pose 正好满足这个条件。
3. **两张图需要的光照不同**:预览图要好看,用柔和的棚拍光和渐变背景。3D 源图要平光、无阴影、白底,否则阴影会被烤进模型贴图,模型一动起来就穿帮。
4. **用途不同**:预览图是选人界面的"海报",要有性格。T-pose 是技术参考图,要中性、对称。

**顺序**:先用照片跑 Prompt 1,挑出满意的一张;再把照片和这张预览图一起附上,跑 Prompt 2。两个 prompt 的风格和服装描述完全一样,四位车手也都不改,这样整套风格才统一。服装上没有任何文字和号码,符合教授的要求。
